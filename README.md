# ربات تلگرام نکات نگهداری خودرو

## این پروژه چیه؟
هر روز، خودکار، یک نکته آموزشی نگهداری ماشین (متن + عکس) توی کانال تلگرامت پست می‌شه. متن‌ها از قبل نوشته شدن (فایل tips.json)، فقط باید عکس هر نکته رو خودت اضافه کنی.

## اضافه‌کردن عکس برای هر نکته
داخل پوشه‌ی photos، یک عکس با نام شماره همون نکته آپلود کن، مثلاً:
- photos/1.jpg → برای نکته شماره ۱ (چک کردن روغن موتور)
- photos/2.jpg → برای نکته شماره ۲ (باد لاستیک‌ها)

اگه عکس یک نکته رو هنوز نذاشتی، مشکلی نیست؛ ربات فقط متن همون روز رو ارسال می‌کنه.

## اضافه‌کردن نکته‌های جدید
فایل tips.json رو باز کن و یک آیتم جدید با id بعدی (مثلاً 31) و title و text اضافه کن. لازم نیست کد رو تغییر بدی.

## تست دستی (بدون صبر تا فردا صبح)
در GitHub، برو به تب Actions → روی workflow «ارسال روزانه نکته مکانیکی» کلیک کن → دکمه Run workflow رو بزن.

## تنظیم اولیه
Secrets لازم در Settings → Secrets and variables → Actions:
- BOT_TOKEN: توکن رباتی که از @BotFather گرفتی
- CHANNEL_ID: یوزرنیم کانالت (مثلاً @my_channel)
